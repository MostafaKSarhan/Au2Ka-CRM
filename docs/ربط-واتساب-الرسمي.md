# ربط واتساب الرسمي (WhatsApp Cloud API)

سجلّ ما تم ضبطه فعلًا في حساب Meta الخاص بالورشة، وما بقي منه. مكتوب هنا
لأن هذه الأرقام لا تظهر في الكود ولا في قاعدة البيانات، ومن يأتي بعدنا
سيحتاج نصف يوم ليجدها مرة أخرى من داخل لوحات Meta.

## المعرّفات

| العنصر | القيمة |
| --- | --- |
| حافظة الأعمال (Business portfolio) | `Au2ka-Marketing` — `1514874926821168` |
| حساب واتساب للأعمال (WABA) | `ورشه سيارات Au2Ka` — `1839114450085607` |
| معرّف الرقم (Phone number ID) | `1163681726818377` |
| الرقم المعروض | ‎+966 55 543 4812 |
| تطبيق Meta | `Au2Ka CRM` — `1802914710980864` — منشور (Live) |
| تصنيف التطبيق | Messaging |
| سياسة الخصوصية | `https://au2ka.com/privacy-policy/` |

التطبيق أُنشئ مخصصًا لـ Au2Ka ولم يُعَد استخدام أي تطبيق قائم. تطبيقات
فاصلة كلاود منتج آخر ولا علاقة له بهذا الحساب، وخلطهما يخلط حسابين
ومسؤوليتين ماليّتين منفصلتين.

سياسة الخصوصية المربوطة بالتطبيق هي سياسة الشركة المنشورة على موقعها
الرسمي، لا نسخة عندنا: النسخة كانت ستتقادم بصمت كلما حدّثوا الأصل، والوثيقة
المُلزِمة يجب أن تبقى على نطاقهم وباسمهم. وهي لا تذكر رسائل واتساب بعدُ —
تغطي المتجر والطلبات — ويُستحسن أن يُضاف إليها سطر عن إشعارات الصيانة
وكيف يوقفها العميل.

## الـ Webhook

| | |
| --- | --- |
| الرابط | `https://au2ka.faslacloud.com/api/v1/webhooks/whatsapp` |
| رمز التحقق | محفوظ في إعدادات واتساب داخل النظام، ولا يُكتب هنا |
| الحقول المشترك بها | `messages` و`message_template_status_update` وحالات التسليم |

تحقّق الاتصال يدويًا بهذا النداء؛ الردّ الصحيح هو إعادة التحدي نفسه
بالحالة 200، وأي رمز خاطئ يردّ 403:

```
curl "https://au2ka.faslacloud.com/api/v1/webhooks/whatsapp?hub.mode=subscribe&hub.verify_token=<الرمز>&hub.challenge=PING"
```

## القوالب

سبعة قوالب مسجّلة عند Meta باللغة العربية، ومربوطة بقوالب النظام عبر
`metaTemplateName`. القالب عند Meta يستعمل أرقامًا — `{{1}}`، `{{2}}` —
بينما قالب النظام يستعمل أسماء، والترتيب بينهما هو العقد: Meta تعدّ
المعاملات ولا تسمّيها، وترفض الرسالة كاملةً (الخطأ 132000) إذا اختلف
عددها عن النص المعتمد.

| كود النظام | اسم القالب عند Meta | التصنيف | عدد المعاملات |
| --- | --- | --- | --- |
| `JOB_WAITING_APPROVAL` | `job_waiting_approval` | Utility | 5 |
| `JOB_COMPLETED` | `job_completed` | Utility | 4 |
| `JOB_DELIVERED` | `job_delivered` | Utility | 4 |
| `SUBSCRIPTION_EXPIRING` | `subscription_expiring` | Marketing | 3 |
| `DOCUMENT_EXPIRING` | `document_expiring` | Marketing | 4 |
| `APPOINTMENT_CONFIRMED` | `appointment_confirmed` | Utility | 3 |
| `APPOINTMENT_REMINDER` | `appointment_reminder` | Utility | 4 |
| `PORTAL_LOGIN_CODE` | `portal_login_code` | Authentication | 1 |

رمز الدخول إلى بوابة العملاء قالب **مصادقة**، ونصّه ليس من عندنا: Meta
تكتبه وتترجمه ولا تسمح بتغيير حرف فيه. والمنصوص عليه في `seed-reference.ts`
هو نصّها العربي حرفًا بحرف حتى يكون سجلّ الرسائل صادقًا فيما وصل العميل.
ويحمل زر «نسخ الرمز»، والرمز يُرسل مرتين — في النص وفي الزر — ولذلك
`metaHasCodeButton` على هذا القالب وحده؛ وإغفال الزر يردّ الخطأ ١٣٢٠٠٠.

وهذا القالب ليس تحسينًا: العميل الذي يسجّل دخوله أول مرة لم يكلّم الورشة
على واتساب قط، فنافذة الـ ٢٤ ساعة مغلقة عليه دائمًا، ولا تقبل Meta إلا
قالبًا معتمدًا. وكان الرمز يُرسل نصًّا حرًّا، أي أنه كان سيفشل في الحالة
الوحيدة التي وُجد لها.

قالبان صنّفتهما Meta تسويقيًا لا خدميًا — تنبيه قرب انتهاء الاشتراك
وتنبيه قرب انتهاء مستند السيارة — لأن في نصّهما دعوة للتجديد. التصنيف
التسويقي أغلى في الفاتورة ويشترط ألا يكون العميل قد أوقف الرسائل. إن
أردنا إرجاعهما إلى Utility فالطريق هو تجريد النص من الدعوة وإبقائه خبرًا
مجرّدًا، ثم إعادة التسجيل.

**أي تعديل على نص قالب في النظام يلزمه إعادة تسجيل القالب عند Meta.**
النص الذي يصل العميل هو نص Meta المعتمد، لا نص النظام؛ وإن اختلف ترتيب
المتغيّرات بينهما وصلت القيم في أماكن خاطئة. يحرس هذا الفحص:

```
cd backend && npm run build && npm run check:templates
```

## ما زال ناقصًا

1. **رمز وصول دائم** — يُولَّد من مستخدم نظام (System User) في إعدادات
   الحافظة بصلاحيات `whatsapp_business_messaging` و
   `whatsapp_business_management`، ثم يوضع على السيرفر في
   `WHATSAPP_ACCESS_TOKEN`. الرمز المؤقت في لوحة التطبيق يسقط بعد ٢٤ ساعة.
2. **ترحيل الرقم إلى Cloud API** — الرقم اليوم مسجّل على تطبيق واتساب
   بزنس على الموبايل. بعد الترحيل لن يعمل على التطبيق، ويصير الإرسال
   والردّ من شاشة الرسائل في النظام. قرار يخصّ الورشة لا يُتخذ عنها.
3. **وسيلة دفع على الحساب** — الرسائل التي يبدأها النظام (جاهزية السيارة،
   تذكير الموعد، قرب انتهاء الوثيقة) تُحاسب عليها Meta بالمحادثة، ولا
   تخرج رسالة واحدة قبل ربط وسيلة دفع.
4. **مزامنة حالة القوالب** — النظام مشترك في `message_template_status_update`
   لكنه لا يقرأه بعد، فاعتماد قالب عند Meta يلزمه اليوم تحديث حالته يدويًا
   في النظام. أتمتتها عمل صغير يستحق أن يُفعل بعد النشر.
